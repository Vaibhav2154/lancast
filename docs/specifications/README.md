# LANCAST — Specifications & Planning Package

This directory contains the foundational research, requirements, architecture, security, evaluation, and testbed specifications for **LANCAST** (established in Phase 0 and maintained across phases).

3. [03_SYSTEM_ARCHITECTURE.md](03_SYSTEM_ARCHITECTURE.md) — Logical architecture and centralized/standalone deployment topologies.
4. [04_THREAT_MODEL.md](04_THREAT_MODEL.md) — Assets, trust boundaries, threat register, and residual risks.
5. [05_EXPERIMENT_PLAN.md](05_EXPERIMENT_PLAN.md) — Baselines, workload scenarios, metrics, and statistical methodology.
6. [06_TECHNOLOGY_DECISIONS.md](06_TECHNOLOGY_DECISIONS.md) — Confirmed stack, architectural decisions, and open ADRs.
7. [07_LITERATURE_REVIEW.md](07_LITERATURE_REVIEW.md) — Focused literature review and gap analysis across all three research pillars.
8. [08_TESTBED_MANIFEST.md](08_TESTBED_MANIFEST.md) — Recorded local development/standalone hardware manifest and central-testbed template.
9. [PROJECT_STATUS.md](PROJECT_STATUS.md) — Phase tracker, confirmed decisions, Phase 0 checklist, and open items.
